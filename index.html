AI Maturity Assessment

Global Leadership Development · Daimler Truck AG

An AI-driven maturity assessment MVP developed during an internship in Global Leadership Development at Daimler Truck AG — evaluating AI literacy and fluency among leadership using a criteria-based scoring methodology powered by Claude AI.

  • Five-dimension AI competency model tailored to E4-level leadership
  • Claude API two-step scoring for reliable evaluation of open-text responses
  • Integrated into internal IT systems with EU AI Act transparency compliance
  • Word-compatible report export for individual and team-level feedback
  • Deployed on Vercel; full handover documentation for internal continuation

Lingua Quattro

Personal Language Learning Application

A serverless, AI-enhanced vocabulary trainer for Italian, French, Spanish and Portuguese — built as a single HTML file and deployed on GitHub Pages. Rooted in spaced repetition research and designed for sustained, self-directed language practice.

  • 2,185 entries across four Romance languages with DE/EN source language toggle
  • SM-2 spaced repetition algorithm with streak tracking and progress export (JSON & CSV)
  • Pre-generated context sentence for each vocabulary entry, enabling authentic in-sentence practice without loading time
  • Native TTS pronunciation using Microsoft voice packages (Helena, Daniel, Alice)
  • Five exercise types: Flashcard, Match, Gap fill, False friends, Context sentence
